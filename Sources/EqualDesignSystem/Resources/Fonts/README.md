# Fonts

DM Sans (variable: optical size 9–40, weight 100–1000; roman and italic), from https://github.com/google/fonts/tree/main/ofl/dmsans, licensed under the SIL Open Font License 1.1 (OFL.txt).

`EqualFonts.register()` registers every .ttf / .otf in this folder at launch. DM Sans sets all text; SF Pro is used only for SF Symbols icons.
