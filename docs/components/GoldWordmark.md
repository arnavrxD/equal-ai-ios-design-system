# GoldWordmark

The "GOLD" wordmark as a vector shape (`EqualGoldWordmarkShape`, artboard 25.1×6.64, from design/icons/gold-wordmark.svg) and a sized view (`EqualGoldWordmark`) for plan badges.

- Variants: colour `#FFD35D` (on black, default) or `#B88D1A` (on white).
- Consumer passes: `width` (25 in the header badge) and `color`.
- Do use it wherever the Figma file shows the GOLD vector.
- Don't stretch it: height follows the artboard ratio.
