# PlanCard

Selectable plan in the sticky plan sheet: 84px tall, `radius-m`, 2px border. Name (`subhead-em` 500), price (`price`) and "/month". Selected: `gold-border` with `shadow-plan-selected` and a green PlanRadio. Gold Plus carries the "Best value" Tag overlapping the top edge.

- Props: `name`, `price`, `period`, `selected`, `best`, `onSelect`. Use two side by side inside a `radiogroup`.
