# ChatList

The home conversation list: `EqualChatListItem`s 12pt apart with hairlines inset to the text column (68pt). The **compact** style (legacy home) stacks 36pt rows 16pt apart without hairlines.

- Consumer passes: `chats`, `style`, `onSelect`, `onAction`.
- Do put it inside the home scroll view; it is a plain stack.
- Don't mix styles in one list.
