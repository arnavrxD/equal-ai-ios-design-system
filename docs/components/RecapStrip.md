# RecapStrip

Light, inline free-week recap for the post-trial price hero: gold "YOUR FREE WEEK WITH EQUAL ▶" eyebrow over three value / label columns split by short rules.

- Pass `eyebrow`, `stats` (`EqualRecapStrip.Stat`) and `onPlay` (the eyebrow replays the recap story).
- Figma labels all three columns "saved"; the default uses saved / calls handled / spam stopped like `EqualRecapCard`.
- Don't use it on dark cards; that is `EqualRecapCard`.
