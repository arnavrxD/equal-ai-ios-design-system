# FeaturePill

52pt glassy gold pill naming one Gold feature: a 36pt 3D icon (or a small composite) and a two-line SemiBold 14 `#666` label. Shown in a horizontal row (gap 20) on the Subscription Expired page and the compact paywall.

- Presets: `.contacts`, `.screening` (iPhone + check), `.languages` (A / अ / అ), `.voices`.
- Pass a title and one to three images for a custom pill.
- Do put them in a horizontal ScrollView; don't wrap them into a grid.
- Figma sets the label in Geist; it is DM Sans here.
