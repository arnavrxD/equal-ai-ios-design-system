# SectionLabel

Section headers. Default: uppercase `section-label` in `legal-text`, centred between hairlines that fade out ("COMPARE PLANS"). `tone="gold"` uses warm gold hairlines and `text-secondary` ("WHAT YOU GET", "FREQUENTLY ASKED QUESTIONS"). `group` gives the left-aligned settings label ("YOUR ASSISTANT", `group-label`).

- Props: `tone`, `group`, `children`.
