# QuickActionTile

Shortcut tiles. **Round** (72px white circle, `shadow-tile`, green SF glyph, 12px label): Message, Discover, Call, Tell Equal. **square** (104×100, `radius-m`, `stroke-medium`): Talk to Equal, Set Instruction, Make a Call in the greeting sheet.

- Props: `label`, `icon`, `mark` (use the Equal mark), `square`.
