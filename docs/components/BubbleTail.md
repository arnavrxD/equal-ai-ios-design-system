# BubbleTail

The curved white tail (17.5×15.1, Figma "Vector 39") at the top-left of the first assistant bubble in a run. A `Shape`, so it can be filled with any colour.

- Variants: none.
- Consumer passes: a fill and a frame; `EqualChatBubble(showsTail:)` places it automatically.
- Do pin its right edge to the bubble's left edge, top-aligned.
- Don't add it to user bubbles or follow-up assistant bubbles.
