# SettingsRow

68px row inside a white `radius-m` settings group (8px 16px padding, `stroke-medium` dividers): 36px icon container · title (`callout-em`) with an optional "New" Tag · subtitle (`footnote`, `text-secondary`) · chevron.

- Props: `icon`, `iconBg`, `title`, `subtitle`, `badge`, `onClick`. Wrap rows in `EqualDS.SettingsGroup`.
- Subtitles summarise the current value ("4 active instructions", "Calm & Friendly · Hindi, English, Telugu").
