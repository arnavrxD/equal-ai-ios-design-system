# Icon

Line icons for UI glyphs, drawn at 24px on a 1.8 stroke in `currentColor`. They stand in for the SF Symbols and Material icons the Figma file uses (chevrons, close, search, mic, keyboard, phone, support…). The exported originals are in the Icons asset group.

- Props: `name`, `size`, `strokeWidth`, `title`.
- Color through CSS `color`; never recolor the 3D illustrations.
