# Tag

Small labels. **gold** = the black "GOLD" plan badge next to the logo (gold gradient text); **status** / **expired** = membership state on the Equal GOLD card; **best** = "Best value" on the Gold Plus plan; **exclusive** / **both** = feature-card corner tags; **new** = green "New" beside a settings row; **deal** = "Limited time deal"; **category** = caller category on the live-call card.

- Props: `kind`, `children`.
- One or two words; uppercase only for `gold` and `deal`.
