# Tag

Small labels. **gold** = the black GOLD plan badge (vector wordmark, gradient stroke; "Gold" and "Gold Plus" render as `EqualPlanBadge`); **goldLight** = the white GOLD badge; **status** / **expired** = membership state on the Equal GOLD card; **bestValue** = "Best value" on the Gold Plus plan; **exclusive** / **bothPlans** = feature-card corner tags; **new** = green "New" beside a settings row; **deal** = "⏰ LIMITED TIME DEAL" on `#272727` with an inner shadow, `#FFF2C3` stroke and soft glows; **category** = caller category on the live-call card.

- Variants: `gold`, `goldLight`, `status`, `expired`, `bestValue`, `exclusive`, `bothPlans`, `new`, `deal`, `category`.
- Consumer passes: the text and the kind.
- Do prefer `EqualPlanBadge` for header badges (it also has TRIAL / TRIAL ENDED / EXPIRED).
- Don't use more than one or two words; uppercase only for `gold` and `deal`.
