# IconButton

Circular icon-only buttons. **solid** 48px white with `shadow-close` closes bottom sheets; **glass** 42px liquid-glass (`glass-button` + `stroke-subtle`) holds the ⋯ menu beside search; **frost** 38px white-70% closes the paywall; **tile** 52px opens the keyboard in the composer.

- Props: `variant` solid | glass | frost | tile, `icon`, `label` (required: it is the accessible name).
- Always top-right for close; never put text inside.
